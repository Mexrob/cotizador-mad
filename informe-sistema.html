1. Resumen Ejecutivo

Cotizador MAD es una aplicación web empresarial robusta y completa, diseñada para la gestión integral de cotizaciones, catálogo de productos y administración de usuarios. Está construida con tecnologías modernas (Next.js 14, React 18, Prisma 6) y desplegada mediante Docker con PostgreSQL 16 y Nginx como reverse proxy.

El sistema incluye un motor de Wizards Configurables que permite crear flujos de cotización dinámicos sin modificar código, convirtiéndose en una plataforma flexible y escalable.

6. Sistema de Wizards Configurables

El componente más innovador del sistema. Permite crear flujos de cotización dinámicos sin modificar código.

6.1 Características

  • 11 tipos de pasos reutilizables
  • Pasos condicionales (mostrar/ocultar según selecciones)
  • Cálculo de precios configurable por fórmula
  • Asignación por roles o usuarios específicos
  • Drag & Drop para reordenar pasos
  • Validación por paso
  • Preview antes de publicar
  • Duplicación de templates

6.2 Pasos Disponibles

  1. step-category - Selección de categoría
  2. step-line - Selección de línea de producto
  3. step-dimensions - Dimensiones (ancho, alto, cantidad)
  4. step-tone - Selección de tono/color
  5. step-grain - Dirección de veta
  6. step-back-face - Cara trasera
  7. step-edge-banding - Cubrecanto
  8. step-handle - Jaladera
  9. step-optionals - Opcionales (exhibición, express, dos caras)
  10. step-summary - Resumen y desglose de precios
  11. step-custom - Paso completamente personalizable

6.3 Wizards Implementados

  • KitWizard (legacy) - Wizard original de kits
  • ConfigurableWizard - Sistema nuevo basado en templates
  • Wizards específicos por línea de producto:
    • ALHU (Alto Brillo)
    • Vidrio
    • Cerámica
    • Europa Sincro
    • Europa Básica
    • Super Mate

8. Despliegue e Infraestructura

8.1 Arquitectura de Contenedores

El sistema se ejecuta en 3 contenedores Docker:

  1. postgres (postgres:16-alpine)
    • Puerto: 5434 → 5432
    • Volumen persistente para datos
    • Healthcheck automático
  2. app (Next.js)
    • Puerto: 3000
    • Hot reload en desarrollo
    • Volumen para uploads
  3. nginx (nginx:alpine)
    • Puerto: 1922 (HTTP) + 443 (HTTPS)
    • Reverse proxy con SSL
    • Servicio de archivos estáticos

8.2 Pipeline de Actualización

El script update.sh automatiza: 1. git fetch + git pull (rama master) 2. npm ci (instalar dependencias) 3. npx prisma generate (regenerar cliente) 4. npx prisma migrate deploy (aplicar migraciones) 5. npm run build (build de producción) 6. pm2 restart (reiniciar app)

11. Conclusiones

Cotizador MAD representa un proyecto empresarial de mediana-alta complejidad que combina:

  • Flexibilidad mediante el sistema de Wizards Configurables
  • Escalabilidad por su arquitectura modular y basada en microservicios Docker
  • Mantenibilidad con TypeScript estricto, Prisma, y tests automatizados
  • Calidad con una política de cero errores en lógica de negocio crítica
  • Internacionalización con soporte para facturación mexicana (CFDI, RFC)

El proyecto está listo para producción y cuenta con un sistema de actualización automatizado, lo que facilita su mantenimiento a largo plazo.
